지금은 DB가 연결되지 않은 체험 모드예요. 체험용 비밀번호는 artdarak 이고, 여기서 고친 내용은 이 브라우저에만 저장됩니다. 실제 서비스에서는 Supabase의 profiles.is_admin 으로 확인합니다.

DB가 연결된 상태예요. profiles.is_admin 이 true 인 필명만 들어올 수 있습니다. 첫 관리자는 Supabase SQL Editor에서 update public.profiles set is_admin = true where pen_name = '내 필명'; 으로 지정해 주세요.
